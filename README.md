# Everyday OS

Build a premium, modern, responsive web application named EVERYDAY OS.
PRODUCT VISION: EVERYDAY OS is an all-in-one daily assistant and personal productivity system designed for everyone. It should feel like a polished operating system, not an ordinary website.
TECHNOLOGY:
React + TypeScript
Tailwind CSS
Reusable components
Clean, maintainable project structure
Prepare for GitHub Pages deployment.
No backend or database for this phase.
DESIGN:
Adaptive dark and light themes.
Initially follow the user's device theme.
Add a working theme toggle.
Premium, minimal, modern interface.
Smooth but subtle transitions.
Excellent mobile-first design.
Support desktop, tablet and Android phone screens.
Consistent spacing, typography, icons and rounded cards.
APP STRUCTURE:
HOME DASHBOARD
EVERYDAY OS branding.
Greeting and current date.
Search interface.
Quick actions section.
Today's overview.
Tasks and upcoming activities area.
Useful empty states when no data exists.
ASSISTANT
Create the visual interface for a future AI assistant.
Chat layout with message input.
Clearly indicate that AI functionality will be added later.
Do not create a fake AI response system.
PLANNER
Clean task and schedule interface.
Prepare reusable task components.
Show an appropriate empty state.
NOTES
Clean notes interface.
Prepare a simple note layout.
TOOLBOX
Create a visually organized toolbox page.
Show planned tools such as Calculator, Unit Converter and Text Tools.
Clearly mark unfinished tools as coming soon.
PROFILE AND SETTINGS
Theme preferences.
Basic app settings.
App information.
NAVIGATION:
Mobile: fixed bottom navigation with Home, Assistant, Planner, Notes and Toolbox.
Desktop: clean sidebar navigation.
Profile/settings accessible from the header.
FUNCTIONAL REQUIREMENTS:
Navigation must work.
Theme switching must work.
Save theme preference locally.
Use responsive layouts.
No login, payment, subscription or database.
No decorative buttons pretending to work.
No unnecessary pages or features.
Keep the application lightweight.
IMPORTANT: Build only Phase 1: the complete visual foundation and working basic navigation. Do not implement advanced features yet.
Make the result feel like a professional, production-quality product. Do not use generic template styling.
